# 活动入口示意图

把每个活动的报名入口截图放这里，命名规则如下，问卷页会自动显示在对应活动卡片顶部：

| 活动 | 文件名 |
| --- | --- |
| 金秋满减（全资） | `entry-manjian-quanzi.png` |
| 金秋满减（混资） | `entry-manjian-hunzi.png` |
| 金秋大场 | `entry-dachang.png` |
| 货补 | `entry-huobu.png` |

- 只支持 `.png`。文件不存在时该区块自动隐藏，不会报错。
- 客户点图可放大查看原图。
- 建议宽度 800-1200px，截图里注意涂掉敏感数据。
